# Spec: 随记页朋友圈化（moments-wechat）

**Status:** ready-for-agent ｜ 来源：用户设计指令（附微信截图）2026-10-21

## 决策

- 随记页（moments）重构为**朋友圈个人页布局**：
  1. 顶部**背景图**（高 ~300px，默认暖色渐变，点击可上传自定义封面）
  2. **头像**压在背景图右下角（下缘越出背景图，微信同款），头像下右侧**签名档**
  3. 下方内容流按**中国区日期倒序分组**：左列日期（今天/昨天/M月/yyyy年M月），右侧该日内容（正文+媒体九宫格+天气 chip）；编辑/删除图标保留在日期行（作者可见）
- **好友主页（profile）同布局复用**：显示好友的封面/头像/签名 + "Ta 发的、@ 了我的"内容流
- User 加 **Signature**（签名，≤100 字）与 **CoverUrl**（封面 storedName）字段；设置页新增签名编辑与封面上传（与头像行整合为「个人资料」区）
- 发布按钮保留（右上/原位）；不做点赞/浏览量

## Out of Scope

日志页（保持现状）；dock 工具；访客记录。
